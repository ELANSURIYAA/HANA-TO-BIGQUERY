SOURCE_LOGIC:
This Calculation View XML defines a CUBE-type Calculation View with outputViewType="Aggregation". The final output is an aggregation over all output columns not marked as measures. The view implements a star-schema pattern with one fact and five dimension lookups. Key logic includes:
- Parameter propagation for IP_VERSION.
- Filtering on fiscal variant, week range, version, and audit trail.
- Hierarchy filtering for CORE_RET nodes.
- Multiple joins to enrich fact data with hierarchy, store, comp flag, calendar week, and profit center text.
- Several calculated columns for comp flags, week numbers, and amount negation.
- The final output (FLAGS node) includes all mapped and calculated columns, with measures aggregated by SUM and all other columns grouped.
- dataCategory="CUBE" and outputViewType="Aggregation" are both present, so the final output requires GROUP BY on all non-measure columns and SUM aggregation on all measures.
