## 3. Final Consumer Flow and Order

The CV_COMP_FIN_FORECAST calculation view follows this transformation sequence:

1. **WEEKLY_SNAPSHOT_DS05** - Projects and filters weekly forecast data from CV_BASE_FIN_WEEKLY_FORECAST_S4
   - Filters: FISCVARNT = 'K4', _BIC_ZIO_SWEEK BETWEEN @IP_WEEK_ENDING_FROM AND @IP_WEEK_ENDING_TO, _BIC_ZIO_VER = @IP_VERSION, _BIC_ZIO_SAUDT IN ('1','10')

2. **STORE_ATTR_ACTUAL** - Projects store attributes from CV_BASE_MD_SRPACT_S4

3. **Join_2** (renamed to Joined_Weekly_Store) - Left joins WEEKLY_SNAPSHOT_DS05 and STORE_ATTR_ACTUAL on _B631_S_PROFTCTR = PRCTR

4. **WEEK_NUMBER** (merged into Joined_Weekly_Store) - Adds calculated column CAL_STORE_WEEK_NUMBER using RIGHTSTR(_BIC_ZIO_SWEEK,2)

5. **COMP_FLAG_FORECAST** - Projects and filters component flags from CV_BASE_MD_COMPFL_S4
   - Filter: COMP_VER = @IP_VERSION

6. **Join_3** (renamed to Joined_Weekly_CompFlag) - Left joins WEEK_NUMBER and COMP_FLAG_FORECAST on _B631_S_PROFTCTR = PRCTR and _BIC_ZIO_SWEEK = ZWEEK

7. **CAL_WEEK** - Projects calendar week data from CV_BASE_MD_RCALWEEK_S4

8. **Join_4** (renamed to Joined_Weekly_CalWeek) - Left joins Join_3 and CAL_WEEK on _BIC_ZIO_SWEEK = ZZWEEK

9. **PROFIT_CENTER_TEXT** - Projects profit center text from CV_BASE_MD_CEPCT_S4

10. **Join_1** (renamed to Joined_Weekly_ProfitCenter) - Left joins Join_4 and PROFIT_CENTER_TEXT on _B631_S_PROFTCTR = PRCTR

11. **FLAGS** - Adds calculated columns:
    - CAL_FS_RX_FLAG: CASE(LEFTSTR(_BIC_ZWWPC_PA1,2),'FS','FS','RX','RX','')
    - CAL_COMP_FLAG: CASE(CAL_FS_RX_FLAG,'FS',FS_COMP_WK,'RX',RX_COMP_WK,FS_COMP_WK)
    - CAL_WEEK_NUMBER: rightstr(_BIC_ZIO_SWEEK,2)
    - _B631_S_AMOUNT: _B631_S_AMOUNT_NEGATIVE * -1

12. **Final SELECT** - Aggregates all measures (SUM) and groups by all non-measure output columns as per CUBE semantics
