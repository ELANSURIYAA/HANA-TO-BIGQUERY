SOURCE_LOGIC:
- The Calculation View is a CUBE with outputViewType="Aggregation", so the final output is aggregated.
- Input parameter IP_VERSION is used as a filter on _BIC_ZIO_VER (single value).
- Input parameters IP_WEEK_ENDING_FROM and IP_WEEK_ENDING_TO are used as a range filter (BETWEEN) on _BIC_ZIO_SWEEK.
- Filter on FISCVARNT = 'K4'.
- Filter on _BIC_ZIO_SAUDT IN ('1', '10').
- Filter on _BIC_ZIO_PSKF IN ('804013', '801000').
- Various projection and join nodes:
  - WEEKLY_SNAPSHOT_DS05: Projects and filters the forecast base view.
  - STORE_ATTR_ACTUAL: Projects store/master attributes.
  - Join_2: LEFT OUTER JOIN on _B631_S_PROFTCTR between WEEKLY_SNAPSHOT_DS05 and STORE_ATTR_ACTUAL.
  - COMP_FLAG_FCST: Projects comp flag and filters by COMP_VER = IP_VERSION.
  - Join_3: LEFT OUTER JOIN on _B631_S_PROFTCTR and _BIC_ZIO_SWEEK between Join_2 and COMP_FLAG_FCST.
  - CAL_WEEK: Projects retail calendar week info.
  - Join_4: LEFT OUTER JOIN on _BIC_ZIO_SWEEK between Join_3 and CAL_WEEK.
  - PROFIT_CENTER_TEXT: Projects profit center descriptions.
  - Join_1: LEFT OUTER JOIN on _B631_S_PROFTCTR between Join_4 and PROFIT_CENTER_TEXT.
  - FLAGS: Final projection and calculation of CAL_WEEK_NUMBER and CAL_BIC_ZIO_SKFQ.
- Final output columns and measures are defined in <logicalModel id="FLAGS">.
- All non-measure output columns must be GROUPed BY, and measures must be aggregated (SUM).
- The final SELECT must match the output columns and aggregation logic of the logical model.
