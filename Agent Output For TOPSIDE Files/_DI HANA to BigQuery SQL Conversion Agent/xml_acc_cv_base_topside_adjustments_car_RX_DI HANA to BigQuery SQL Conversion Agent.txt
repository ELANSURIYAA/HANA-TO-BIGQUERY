SOURCE_LOGIC:
The source artifact is a SAP HANA Calculation View XML with root scenario id CV_BASE_TOPSIDE_ADJUSTMENTS_CAR. It contains a single data source, CVS_FRIP.TOPSIDE_ADJUSTMENTS_VT_CAR, and a single ProjectionView node named TOPSIDE_ADJUSTMENTS. The projection passes through all required columns via direct 1:1 mappings with no calculated columns and no joins.

An explicit filter is applied on MANDT in the projection node:
- MANDT IN ('110', '200') semantically, though the XML does not provide datatype metadata for MANDT.

The logical model defines:
- 9 non-measure output attributes
- 16 base measures, all with aggregationType="sum"

The root element explicitly specifies:
- dataCategory="CUBE"
- outputViewType="Aggregation"

Therefore the final output requires GROUP BY on every non-measure output column and SUM aggregation on every measure. Even though the only transformation node is a projection, the final BigQuery SQL must return aggregated output per the logical model, not a flat row-level projection.
