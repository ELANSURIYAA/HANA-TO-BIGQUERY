SOURCE_LOGIC:
- The source artifact is a SAP HANA Calculation View XML with a single Projection node over base table SAP_S4.ZTSRP_ATTR_ACT.
- Root attributes:
  - dataCategory="CUBE"
  - outputViewType="Aggregation"
- Because dataCategory is CUBE and outputViewType is Aggregation, the final output requires GROUP BY on every non-measure output column and aggregation on each measure column.
- The Projection node selects a defined list of columns from the base table and applies one explicit filter:
  - MANDT IN ('120', '200')
- There are no joins, calculated columns, unions, parameters, placeholders, or procedural steps in the provided XML.
- The logical model defines:
  - Output attributes: all listed non-measure columns
  - Base measures aggregated by SUM:
    - RX_HRS_OPER
    - FS_HRS_OPER
    - RETAIL_SQFT_AMT
    - TOTAL_SQFT_AMT
- Therefore the semantic BigQuery equivalent is:
  1. Read from SAP_S4.ZTSRP_ATTR_ACT
  2. Filter to MANDT in 120/200
  3. Group by all non-measure attributes
  4. Sum the four measure columns
