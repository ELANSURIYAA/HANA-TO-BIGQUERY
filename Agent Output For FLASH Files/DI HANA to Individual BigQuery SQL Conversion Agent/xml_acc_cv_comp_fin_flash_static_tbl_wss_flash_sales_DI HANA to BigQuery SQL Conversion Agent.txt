SOURCE_LOGIC:
- The source artifact is a SAP HANA Calculation View XML for CV_COMP_FIN_FLASH_STATIC.
- Root element attributes indicate:
  - dataCategory="CUBE"
  - outputViewType="Aggregation"
- Therefore, the final output requires GROUP BY on every non-measure output column and aggregation on every measure according to the logical model.
- The view contains a single ProjectionView node named Projection_1.
- Projection_1 reads from one external source object only: CVS_FRIP.Table::TBL_WSS_FLASH_SALES.
- All output columns are direct 1:1 mappings from the source object; there are no calculated columns, joins, unions, filters, variables, or parameters present in the provided XML.
- The logical model defines:
  - 40 non-measure output attributes
  - 15 measures with explicit aggregation rules
- Because this is a CUBE/Aggregation view, the BigQuery equivalent must aggregate:
  - SUM on additive numeric measures
  - MAX on timestamp-like update measures
- Since no additional transformation nodes exist beyond the projection, the business logic is effectively:
  - read rows from the source table/view
  - project the specified columns
  - aggregate by all non-measure attributes
