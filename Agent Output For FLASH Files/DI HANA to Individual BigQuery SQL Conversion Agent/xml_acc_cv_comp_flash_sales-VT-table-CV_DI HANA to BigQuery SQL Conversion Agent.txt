SOURCE_LOGIC:
This is a SAP HANA Calculation View XML artifact. The root Calculation:scenario has:
- dataCategory = "CUBE"
- outputViewType = "Aggregation"

Therefore the final output is aggregated output and requires GROUP BY plus aggregation.

The view builds a flash sales composite result from multiple external calculation views:
1. NAVIX supplies the base retail-day grain keys.
2. FS_SALES filters TLOGF to RECORDQUALIFIER = 5 and keeps sales rows.
3. FS_DISCOUNT filters TLOGF to RECORDQUALIFIER = 6 and keeps discount rows.
4. RX_SALES filters TLOGF to RECORDQUALIFIER = 5 and keeps RX sales rows.
5. SCRIPTS uses TLOGF_X to bring RX counters, customer type, workstation, and update timestamp.
6. NAVIX_2 adds CURRENCY by joining NAVIX grain to SCRIPTS grain.
7. SCRIPT_KPIs derives:
   - FS units from customer type
   - numeric RX counts from text-or-empty source fields
   - COVID units from workstation/customer-type logic
8. Parameter views filter CV_BASE_PARAMETERS into code lists:
   - FS_RETAIL_TYPE_CODE
   - EMP_DISC_TYPE_CODE
   - RX_RETAIL_TYPE_CODE
   - FS_DISC_TYPE_CODE
   - RX_RETAIL_TYPE_CODE for COVID
9. Inner joins keep only fact rows whose retail/discount type exists in those parameter code lists.
10. COVID_SALES uses CV_BASE_TLOGF_COVID sales amount and joins to RX retail type codes.
11. A union stacks six branches:
   - scripts metrics
   - FS sales
   - employee discount
   - RX sales
   - FS discount
   - COVID sales
   Non-applicable metrics are set to NULL in each branch.
12. COMBINE_DATA aggregates unioned rows by:
   - MANDT
   - RETAILSTOREID
   - BUSINESSDAYDATE
   - TRANSCURRENCY
   - ZZ_UPD_TIMESTAMP
13. MERGED inner joins NAVIX to COMBINE_DATA on:
   - MANDT
   - RETAILSTOREID
   - BUSINESSDAYDATE
14. Logical model exposes only:
   - Attributes: MANDT, RETAILSTOREID, BUSINESSDAYDATE, TRANSCURRENCY
   - Measures: ZZ_UPD_TIMESTAMP, FS_SALESAMOUNT, REDUCTIONAMOUNT, RX_SALESAMOUNT, CAL_FS_UNITS, EMP_REDUCTIONAMOUNT, CAL_RX_CNT_GE84_NS, CAL_RX_CNT_GE84_RE, CAL_RX_CNT_NS, CAL_RX_CNT_RE, RX_UPD_TIMESTAMP, FS_UPD_TIMESTAMP, SCRIPTS_UPD_TIMESTAMP, CVD_AMOUNT, CAL_CVD_UNITS

Because this is a CUBE/Aggregation view, the final SELECT must GROUP BY:
- MANDT
- RETAILSTOREID
- BUSINESSDAYDATE
- TRANSCURRENCY

And aggregate measures using the logical model aggregation types:
- MAX for timestamp measures
- SUM for numeric measures

      MANDT,
      RETAILSTOREID,
      BUSINESSDAYDATE,

      s.MANDT,

      s.WORKSTATIONID
