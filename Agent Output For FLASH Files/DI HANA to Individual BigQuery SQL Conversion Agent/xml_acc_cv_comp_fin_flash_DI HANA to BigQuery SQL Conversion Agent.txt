SOURCE_LOGIC:
This is a SAP HANA Calculation View XML artifact. The root Calculation:scenario has:
- dataCategory="CUBE"
- outputViewType="Aggregation"

Therefore the final output is aggregated and requires GROUP BY plus measure aggregation.

The view:
1. Reads flash sales data from CV_BASE_FIN_FLASH_SALES_CAR.
2. Filters out store IDs between '0000020000' and '0000024999' inclusive, keeping only store IDs less than '0000020000' or greater than '0000024999'.
3. Filters BUSINESSDAYDATE between IP_WEEK_ENDING_FROM and IP_WEEK_ENDING_TO.
4. Computes a week-ending date from BUSINESSDAYDATE using HANA date/weekday logic.
5. Left joins to retail calendar on computed week-ending date = ZRWENDDATE to enrich with week/year/period attributes.
6. Joins store attributes by store number.
7. Inner joins hierarchy data to keep only PRCTR values whose hierarchy parent matches *CORE_RET* and HRYVALTO='99991231'.
8. Left joins comp flag data filtered by IP_VERSION on PRCTR and retail week.
9. Computes:
   - CAL_SCRIPTS_90AS3
   - CAL_COMP_FLAG from FS_COMP_WK and RX_COMP_WK
   - CAL_WEEK_NUMBER from last 2 chars of ZZWEEK
10. Builds an employee discount aggregate grouped by dimensional columns and computes synthetic PRCTR values:
   - CAL_COMP_FLAG='1' -> '0000562075'
   - CAL_COMP_FLAG='0' -> '0000562076'
11. Joins employee discount aggregates to a filtered store-attribute set limited to PRCTR in ('0000562075','0000562076').
12. Unions:
   - sales rows from CALCULATIONS with EMP_REDUCTIONAMOUNT nulled
   - employee-discount rows from Join_4 with sales/script/cvd measures nulled
13. Left joins profit center text by PRCTR.
14. Final output is aggregated per logical model:
   - all logical-model attributes grouped
   - measures aggregated per logical-model aggregationType

  - The original nested replace(weekday(...),6,-1) behavior was preserved via CASE logic.
