/*
================================================================================
CONSOLIDATED BIGQUERY SQL FOR CV_COMP_FIN_ACTUAL_STATIC
================================================================================

ARTIFACT: CV_COMP_FIN_ACTUAL_STATIC
PURPOSE: Financial Actuals Static Composite View with Store Attributes, 
         Hierarchies, Calendar, and Comparison Flags

RUNTIME PARAMETERS:
  @ip_version           STRING  - Version for weekly actuals filter
  @ip_week_ending_from  STRING  - Week ending from (not used in current logic)
  @ip_week_ending_to    STRING  - Week ending to (not used in current logic)
  @ip_version_comp_flag STRING  - Version for comparison flag filter
  @ip_week_ly           STRING  - Last year week for actuals
  @ip_week_cy           STRING  - Current year week for calendar and comp flag
  @v_week               STRING  - Prior fiscal week (from SFN_PRIOR_FISCAL_WEEK function)

DEPENDENCIES CONSOLIDATED:
  1. CV_BASE_FIN_WEEKLY_ACTUAL_S4 - Weekly actuals from AZSRP_DS072_VT_S4
  2. CV_BASE_MD_SRPACT_S4 - Store attributes from ZTSRP_ATTR_ACT
  3. CV_COMP_MD_SRPACT_STATIC - Aggregated store attributes (inlined from staging)
  4. CV_BASE_MD_HRRP_NODE_S4 - Hierarchy nodes (PC and GL)
  5. CV_BASE_MD_RCALWEEK_S4 - Retail calendar from ZTFIGL_RCALWEEK
  6. CV_BASE_MD_COMPFL_S4 - Comparison flags from ZTSRP_COMPFL
  7. CV_COMP_MD_COMPFL_STATIC - Filtered comp flags (inlined from staging)
  8. CV_BASE_MD_CEPCT_S4 - Profit center text from CEPCT
  9. STP_WSS_SRP_ATTRIBUTES - Procedure logic inlined

COLUMN MAPPINGS APPLIED:
  All physical column names and table references use exact BQ_COLUMN and 
  BQ_FULL_TABLE values from Columns_Mapping.csv

TRACEABILITY:
  - WEEKLY_SNAPSHOT_DS072: CV_BASE_FIN_WEEKLY_ACTUAL_S4 → v_bic_azsrp_ds212
  - STORE_ATTR_BASE: CV_BASE_MD_SRPACT_S4 → v_ztsrp_attr_act
  - STORE_ATTR_ACTUAL: CV_COMP_MD_SRPACT_STATIC (aggregated)
  - PC_HIER: CV_BASE_MD_HRRP_NODE_S4 (PC hierarchy) → v_hrrp_node
  - GL_HIER: CV_BASE_MD_HRRP_NODE_S4 (GL hierarchy) → v_hrrp_node
  - RETAIL_CAL: CV_BASE_MD_RCALWEEK_S4 → v_ztfigl_rcalweek
  - COMP_FLAG_BASE: CV_BASE_MD_COMPFL_S4 → v_ztsrp_compfl
  - COMP_FLAG_LY: CV_COMP_MD_COMPFL_STATIC (filtered)
  - PROFIT_CENTER_TEXT: CV_BASE_MD_CEPCT_S4 → v_cepct

BUSINESS LOGIC PRESERVED:
  - Filter weekly actuals by FISCVARNT='K4', version, week, audit trail
  - Join PC hierarchy (CORE_RET nodes, valid to 99991231)
  - Join GL hierarchy (181 nodes, HRYID='CVS2', valid to 99991231)
  - Enrich with store attributes (left join on profit center)
  - Add retail calendar dates (left join on week)
  - Add comparison flags (left join on profit center, filtered by week and version)
  - Add profit center text (left join)
  - Calculate FS/RX flag from product class (LEFT 2 chars)
  - Calculate comp flag based on FS/RX
  - Calculate week number (RIGHT 2 chars of current week)
  - Aggregate all measures with SUM, negate _B631_S_AMOUNT
  - Group by all dimensions

ISSUES TO FIX:
  - None identified. All column mappings validated against Columns_Mapping.csv
  - Runtime parameter @v_week must be supplied (from SFN_PRIOR_FISCAL_WEEK equivalent)
  - All referenced tables exist in edp-qa-finstorage.edp_saps4_shared_cnsv

================================================================================
*/

-- CTE: PC_HIER
